## 一、 大廳「開始遊戲」過渡防閃退鐵律 (`StandardQuiz.jsx` & `SpellingGame.jsx`)

1. **嚴禁在 `queue` 空陣列時呼叫 `onBack()`**：
   - 當學生在大廳選好冊別、點擊「🚀 開始遊戲 START」進入 `StandardQuiz` 或 `SpellingGame` 時，第一個 render 週期 `queue` 陣列可能尚未由 `useEffect([settings, words])` 計算完成（此時 `queue.length === 0`）。
   - **絕對禁止**在自動開局的 `useEffect` 中寫 `if (queue.length === 0) return onBack();`！否則學生一按開始遊戲就會立刻被踢回大廳。
   - **正確寫法**：
     ```javascript
     useEffect(() => {
       if (queue.length > 0 && !hasStarted) {
         handleStart();
       }
     }, [queue.length]);
     ```
2. **題數設定空值防護**：
   - 篩選題數時必須檢查 `if (settings?.count && settings.count !== 'all')`，防止 `settings.count` 為 `undefined` 時 `slice(0, NaN)` 產生空題庫。

## 二、 單字拼寫王 (`SpellingGame.jsx`) 多詞膠囊與平板友善規範

1. **複合詞分組 (`parsePhrase`)**：
   - 遇到含空格的片語或複合詞（如 `ice cream`, `social studies`）時，自動依空格拆分為獨立詞塊群組 (`wordGroups`)，標點符號自動預填不計入空格。
2. **點擊即填與退格重排**：
   - 支援點擊下方字母磚自動填入第一個空格（平板免拖曳），並提供退格與重排容錯。

## 三、 手寫塗鴉檢定 (`HandwritingGame.jsx`) 規範

1. **判定彈窗獨立浮層**：
   - 手寫評測結果彈窗必須脫離四線三格 `aspect-ratio` 畫布容器，作為獨立浮層渲染，確保在任何螢幕比例下「下一題」按鈕皆 100% 完整露出且可點擊。

6. **四大測驗模式分流與題庫模組化架構奠基 (2026-11-04 與 Mark 定案共識)**：
   - **核心動機**：課本單元小考僅針對特定單元範圍，而教育部 Test My English Pre-A1 與各縣市國小學力檢測 (SAA) 著重於全真生活情境、長篇題組與綜合素養，兩者在「施測目的、題型結構、時間規範與評量等第」上完全不同，因此檢定館全面確立四大測驗分流。
   - **四大測驗分流定義 (`EXAM_TRACKS`)**：
     1. **`textbook`（課本單元進度檢定）**：
        - 1~8 冊、字母專冊與國一先修，共 1,289 題。
        - 支援自選冊別與單元、自選 10/20/50 題規格，本年級達標 60% 核發學習金幣。
     2. **`tme-preA1`（Test My English Pre-A1 官方模擬）**：
        - 依教育部 TME 官方規範：**30 題標準卷（聽力 15 題 + 閱讀 15 題）**，建議作答 35 分鐘。
        - 聽力：聽音選圖 (`L-PIC`, 5題)、聽音選字 (`L-WORD`, 5題)、聽問句選回應 (`L-RESP`, 5題)，每題播音 2 次。
        - 閱讀：看圖選字 (`V-PIC`, 5題)、生活告示圖表配合 (`R-MATCH`, 5題)、看圖是非判斷 (`R-TF`, 5題)。
        - 評量：答對 21/30 題 (>= 70%) 通過 Pre-A1 等級。
     3. **`ministry-assessment`（教育部縣市學力檢測 SAA 實戰模考）**：
        - 依臺中教育大學 SAA 臺灣學生學習成就評量試卷結構，針對 4、5、6 年級施測。
        - 聽力三大題：辨識句意 (`L-SENT`)、基本問答 (`L-QA`)、言談理解 (`L-CONV`)。
        - 閱讀二大題：單題字彙語法 (`G-MC`, `V-MEAN`)、篇章/圖表閱讀題組 (`R-PASSAGE`, `R-COMP`)。
        - 評量：三級成就等第（精熟 Proficient >= 85%、基礎 Basic 60%~84%、待加強 Developing < 60%）。
     4. **`mistakes`（個人易錯題弱點擊破室）**：
        - 跨軌道自動收集個人歷史錯題，題數不足時自本年級題庫補滿。連續答對 2 次判定精熟並移出易錯池。
   - **題庫模組化儲存中心 (`src/data/exam/`)**：
     - `examTracks.js`：四大模式軌道中樞與規格。
     - `tmePreA1Meta.js` & `tmePreA1Bank.js`：Pre-A1 官方規範與題庫骨架。
     - `saaExamMeta.js` & `saaExamBank.js`：學力檢測 SAA 試卷規範、篇章資料結構與題庫骨架。
     - `index.js`：統一出口，支援 `getQuestionsByTrack()` 與後設資料查詢。
     - 保持與 `hereWeGoMcqBank.js` 100% 相容，保證 `smoke_test.mjs` 靜態品質閘門不中斷。
   - **組卷與題型擴充 (`examBlueprint.js`)**：
     - 新增題型支援：`L-SENT`（辨識句意）、`L-QA`（基本問答）、`L-CONV`（言談理解）、`R-PASSAGE`（篇章閱讀）。
     - 前端檢定館 (`PureMcqExamView.jsx`) 實裝四大模式即時切換與規格資訊預覽卡，當 TME 與 SAA 處於建置期時呈現清晰專業的試卷結構與貼心引導，課本檢定零回歸維持秒開。
