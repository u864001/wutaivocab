# 經典/聽力選擇題 (`StandardQuiz`)、單字拼寫王 (`SpellingGame`) 與手寫塗鴉 (`HandwritingGame`) 專屬規範

> **對應檔案**：`src/games/quiz/StandardQuiz.jsx`、`src/games/spelling/SpellingGame.jsx`、`src/games/handwriting/HandwritingGame.jsx`

---

## 一、 大廳「開始遊戲」過渡防閃退鐵律 (`StandardQuiz.jsx` & `SpellingGame.jsx`)

1. **嚴禁在 `queue` 空陣列時呼叫 `onBack()`**：
   - 當學生在大廳選好冊別、點擊「🚀 開始遊戲 START」進入 `StandardQuiz` 或 `SpellingGame` 時，第一個 render 週期 `queue` 陣列可能尚未由 `useEffect([settings, words])` 計算完成（此時 `queue.length === 0`）。
   - **絕對禁止**在自動開局的 `useEffect` 中寫 `if (queue.length === 0) return onBack();`！否則學生一按開始遊戲就會立刻被踢回大廳。
   - **正確寫法**：
     ```javascript
     useEffect(() => {
       if (queue.length > 0 && !hasStarted) {
         handleStart();
       }
     }, [queue.length]);
     ```
2. **題數設定空值防護**：
   - 篩選題數時必須檢查 `if (settings?.count && settings.count !== 'all')`，防止 `settings.count` 為 `undefined` 時 `slice(0, NaN)` 產生空題庫。

---

## 二、 單字拼寫王 (`SpellingGame.jsx`) 多詞膠囊與平板友善規範

1. **複合詞分組 (`parsePhrase`)**：
   - 遇到含空格的片語或複合詞（如 `ice cream`, `social studies`）時，自動依空格拆分為獨立詞塊群組 (`wordGroups`)，標點符號自動預填不計入空格。
2. **點擊即填與退格重排**：
   - 支援點擊下方字母磚自動填入第一個空格（平板免拖曳），並提供退格與重排容錯。

---

## 三、 手寫塗鴉檢定 (`HandwritingGame.jsx`) 規範

1. **判定彈窗獨立浮層**：
   - 手寫評測結果彈窗必須脫離四線三格 `aspect-ratio` 畫布容器，作為獨立浮層渲染，確保在任何螢幕比例下「下一題」按鈕皆 100% 完整露出且可點擊。

## 四、 課本題庫檢定館 (`PureMcqExamView.jsx` & `hereWeGoMcqBank.js`)

1. **核心定位与 A/B 雙入口架構**：
   - **路由**：`/?view=mcq-exam`
   - **A 入口（首頁獨立第 4 大館）**：首頁 7 大館依序為：`霧臺小鎮生活冒險 RPG` (`town`) ➔ `英語單字冒險館` (`lobby`) ➔ `雙語聽說探險館` (`langlab`) ➔ `課本題庫檢定館` (`mcq-exam`) ➔ `自然發音探索館` (`phonics`) ➔ `ClassQnA` ➔ `自編英語電子教科書` (`textbook`)。
   - **B 入口（雙語聽說探險館內卡片）**：`LanguageLabHub.jsx` 主選單第 3 張卡片「📝 課本題庫檢定」直通 `mcq-exam`。
   - **單字館純淨化**：`Lobby.jsx` 移除 `mcq-exam`，維持 100% 純單字遊戲館。
2. **全冊百題原創類題庫 (`src/data/hereWeGoMcqBank.js`) 與 7 道品質閘門契約**：
   - 涵蓋 **1 年級大寫字母專冊 (`'g1'`)、2 年級大小寫字母專冊 (`'g2'`)、Here We Go 第 1～8 冊 + 國一先修 (Book 9)**，**全 11 冊每冊均達 100 題以上（全站共 1,289 題）**：
     - **一年級大寫字母專冊 (`book: 'g1'`，120 題)**：零英語單字，全中文題幹搭配 `zh-TW` 語音讀題按鈕，專注檢測 `A~Z` 大寫字母先後順序、空格缺漏字母與正確字母序列。
     - **二年級大小寫字母專冊 (`book: 'g2'`，125 題)**：零英語單字，全中文題幹搭配 `zh-TW` 語音讀題按鈕，專注檢測 `Aa~Zz` 大轉小、小轉大、大小寫正確配對、小寫空格缺漏與小寫字母序列。
     - **三至六年級 (`book: 1~9`，共 1,044 題)**：涵蓋「文法與依題意選答 (`grammar`)」與「情境對話選答 (`dialogue`)」，搭配 `en-US` 語音讀題。
   - **本年級嚴格綁定 (`isBookInOwnGrade`)**：1 年級綁定 `'g1'`、2 年級綁定 `'g2'`、3 年級綁定 `1, 2`、4 年級綁定 `3, 4`、5 年級綁定 `5, 6`、6 年級綁定 `7, 8, 9 (國一先修)`。跨年級自主練習不發放金幣亦不計入英雄榜。
   - 每題具備唯一固定編號 `id` (`hwg_b{book}_{seq}`)、3~4 個不重複選項、唯一正解索引 `answer` 與完整中文解析 `explanation`。
   - `scripts/smoke_test.mjs` Phase 0 內建靜態契約檢查，強制驗證全部 11 冊每冊題數 `>= 100`、ID 唯一、選項無重複；後續若由輕量模型（如 Flash）擴充題庫，必須使用規則鎖定產生器並通過 `smoke_test.mjs` 驗證，嚴禁混入無解析或重複選項之劣質題目。
3. **專業語言測驗零捲動 (`100dvh`) 5 步流程規範**：
   - **全域頂欄隱藏**：當 `currentView === 'mcq-exam'` 時隱藏全域 `<Header />`，杜絕測驗中切換雙語與外部干擾。
   - **零遊戲元素**：不呼叫任何 `soundEngine` 遊戲音效、不播放彩帶動畫，採用魯凱日/夜柔焦背景＋中央高對比固定高度檢定容器（`h-[100dvh]`）。
   - **空間不足時允許滑動（嚴禁重疊）**：電腦／平板空間足夠時一頁呈現；手機、未放大視窗時，設定頁主體、作答頁題幹區、結果頁主體一律 `overflow-y-auto`，**嚴禁用 `overflow-hidden` + `flex-1 min-h-0` 硬塞**（曾導致「上半冊／下半冊」被「選擇題數」區塊覆蓋而點不到）。設定頁「開始檢定」鈕固定在底部列不隨內容捲走。`smoke_test.mjs` Phase 5 以 375×667 手機尺寸檢查上半冊、下半冊、全選、題數、開始鈕皆可點擊。
   - **手機文字精簡**：補充說明一律 `hidden sm:inline` 或 `hidden md:inline`，手機只留必要標籤。
   - **Step 1（選範圍）**：支援切換「📚 課本範圍檢定」與「📓 個人易錯題複習 (`wutai_mcq_mistakes_${studentId}`)」。易錯題不足目標題數時，自動從學生本年級題庫隨機抽題補滿；在易錯題複習中對同一題**連續答對 2 次 (`streak >= 2`)** 自動從易錯池移除。
   - **Step 2（選題數）**：提供 `10 題`、`20 題`、`50 題` 三種規格。
   - **Step 3（一頁一題作答）**：頂端三欄極簡列（左：`← 離開`、中：`1年大寫字母檢定 / 2年大小寫字母檢定 / 第 X 冊檢定 / 國一先修檢定 / 個人易錯題複習`、右：`題號進度 + 🚩 標記`），步驟與題目間採 `150ms` 原地平滑淡入淡出。題幹自動偵測中文或英文切換 `zh-TW` / `en-US` 語音讀題。
   - **Step 4（金幣核發公式）**：選本年級冊別（或個人易錯題複習）且**答對率達 60% 以上**，核發 `Math.min(20, Math.round(題數 * 答對率 * 0.4))` 枚學習金幣（10 題全對 = 4 金幣、20 題全對 = 8 金幣、50 題全對 = 20 金幣，單次上限 20 金幣）。
   - **Step 5（單題翻頁式檢定報告）**：得分方塊旁直接顯示本次金幣（`🪙 +8`，不另做金幣說明卡；未發金幣原因放在 `title` 提示）；右欄採「單題翻頁卡（`◀ 上一題 / 下一題 ▶`）」檢視錯題或全部題目詳解。手機上下排列可滑動，確保看得到每題解析。
4. **英雄榜「課本題庫檢定」三大累計榜單 (`LeaderboardView.jsx` 第 6 區 & `recordMcqExamStats`)**：
   - **位置與跨年級支援**：位於英雄榜最下方（緊接於 `5. 雙語聽說` 之下），支援 **一年級～六年級分年級榜** 與 **全校大亂鬥**。
   - **採計門檻（防洗榜機制）**：僅限學生作答**本年級對應冊別（或個人易錯題複習）**且**單次答對率 ≥ 60%** 的場次，才會累加寫入當週累計數據（`totalCorrect` 累計答對題數、`totalAttempted` 累計作答題數，儲存在 `leaderboard.time` 欄位顯示 `累計X題`）：
     1. **`👑 檢定測驗王` (`mode = 'mcq-king'`)**：綜合加權積分 `Math.round(累計答對題數 × 累計總答對率)`（單位：`分`），同時獎勵題數多且正確率高的頂尖學生。
     2. **`🔥 刷題勤學王` (`mode = 'mcq-diligent'`)**：累計答對總題數 `totalCorrect`（單位：`題`），鼓勵學生多做練習。
     3. **`🎯 百發精準王` (`mode = 'mcq-accurate'`)**：累計總答對率 `Math.round((totalCorrect / totalAttempted) * 100)`（單位：`%`），須當週**累計作答滿 20 題以上**方具上榜資格；同分時依累計作答總題數 (`time DESC`) 排序。

5. **專業語言測驗藍圖（2026-10-30 與 Mark 定案共識，後續擴題一律遵守）**：
   - **大題（`section`）與題型代碼（`taskType`）**：每題必須標記，組卷依此運作。
     | section | taskType | 題型 | 素材 |
     | :--- | :--- | :--- | :--- |
     | `alphabet`（一、二年級） | `A-ORDER` 字母前後／順序、`A-MISSING` 空格缺漏字母、`A-CASE` 大小寫轉換／配對、`A-SOUND` 聽音選字母 | 純文字／TTS |
     | `listening` | `L-WORD` 聽音選字、`L-PIC` 聽音選圖、`L-TF` 看圖聽句判斷是非、`L-RESP` 聽問句選回應、`L-DLG` 聽對話回答 | TTS／線稿 |
     | `vocabulary` | `V-PIC` 看圖選單字、`V-WORD` 看字選圖、`V-MEAN` 依語意選單字（純文字） | 線稿／純文字 |
     | `grammar` | `G-MC` 文法選擇（句中填空）、`G-DLG` 完成對話、`G-CTX` 依上下文選出正確句子 | 純文字 |
     | `reading` | `R-TF` 看圖讀句判斷是非、`R-CLOZE` 短文填空／克漏字（題組）、`R-COMP` 閱讀理解（題組）、`R-MATCH` 配合題 | 純文字／圖表 |
   - **題目資料格式 v2**：`{ id, track, book, unit, section, taskType, difficulty(1易/2中/3難), reviewed, groupId, media:{audioText,imageId}, question, options, answer, explanation }`。`track` 為 `textbook | tme-preA1 | gept-kids | ministry-assessment`。**只有 `reviewed: true` 的題目會進入正式組卷**；輕量模型新增的題目一律先標 `reviewed: false`，經審核後才改為 `true`。題庫檔 `hereWeGoMcqBank.js` 現為**唯一資料來源**（舊產生器 `expand_mcq_bank_100_per_book.mjs` 已退役，嚴禁再執行覆蓋）。
   - **組卷規則**：大題順序固定為 **字母 → 聽力 → 字彙 → 文法與用法 → 閱讀**；大題內同題型相鄰、由易到難；題組（`groupId`）整組抽出不拆散。題庫缺少的題型，其題數自動分給現有題型。**10 題只取 2～3 種題型**；20 題、50 題依題庫現有題型比例分配。**易錯題複習維持隨機**（屬複習，非正式試卷）。
   - **第 0 頁「本次測驗說明」**：按「開始檢定」後先顯示一頁精簡說明（範圍、總題數、各大題題號區間；含聽力時提示戴耳機），學生按「開始作答」才進入第 1 題並**開始計時**。
   - **計時**：只顯示「已用時間」（不倒數）。倒數計時保留給未來的正式模擬卷模式。
   - **中斷與幽靈測驗處理**：作答過程只存在學生瀏覽器，**交卷前不寫入任何雲端資料**，因此伺服器端不會留下幽靈測驗。為避免斷線、誤關分頁損失進度，作答中每次作答都把進度快照存到 `localStorage`（`wutai_mcq_inprogress_${studentId|guest}`，含 `startedAt`）：重新進入檢定館時若快照**未滿 6 小時**，提示「繼續上次的檢定／放棄」；**超過 6 小時自動刪除**。交卷或主動放棄時立即清除。
   - **聽力播放規則**：課本小測驗**允許學生自行重複播放**；未來的正式模擬卷（GEPT Kids／TME）才比照官方規則（例如 GEPT Kids 每題自動播 2 次、不可手動重播）並依官方時間進行。
   - **口說**：不放進檢定館，維持在雙語聽說館另外施測。
   - **結果報告**：除總分外，顯示**各大題／題型分項成績**（例如「文法選擇 7/8、完成對話 3/4」），作為弱點診斷。
   - **分期**：A 期：現有文字題全面標記 `section/taskType/difficulty`，修正或刪除不佳題目，重寫套版解析，加上第 0 頁、分段組卷、分項成績、進度快照 → B 期：TTS 聽力題 → C 期：共用黑白線稿庫與看圖題（一張線稿可用於多種題型，閱讀題組等專用圖例外） → D 期：閱讀題組 → E 期：TME Pre-A1／GEPT Kids／學力檢測模擬卷（需先取得官方樣題確認題型比例）。
